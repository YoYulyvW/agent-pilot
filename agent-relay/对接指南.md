# AgentPilot 对接使用指南

> 手机 App（AgentPilot）↔ 中继服务（relay_server.py）↔ 各智能体（WorkBuddy / Codex / Cuckoo-Code / Claude Code…）

---

## 一、域名（中继地址）怎么填

App「设置」里填的「中继地址」，是**手机能访问到的 relay_server.py 地址**。分三种情况：

### 场景 1：局域网（手机和电脑连同一个 WiFi）✅ 最简单

1. 电脑上启动中继服务（`kai-fan-le-helper` 内置，端口 **8860**）
2. 查电脑局域网 IP —— Windows 打开 CMD 输入 `ipconfig`，看「IPv4 地址」，例如 `192.168.1.100`
3. 手机 App 设置里填：`http://192.168.1.100:8860`
4. 确认电脑防火墙放行 8860 端口

> ⚠️ 不要填 `http://127.0.0.1:8860` —— 那是电脑自己的本机地址，手机连不到。

### 场景 2：内网穿透（手机在外网，电脑在家/公司）

把电脑的 8860 端口穿透到公网，任选其一：

| 方案 | 做法 | 手机填 |
|------|------|--------|
| Cloudflare Tunnel（免费、简单） | `cloudflared tunnel --url http://localhost:8860` | 终端打印的 `https://xxx.trycloudflare.com` |
| frp | 配 frpc 把 8860 映射到有公网的 frps | `https://你的域名:端口` |
| ngrok | `ngrok http 8860` | `https://xxx.ngrok.io` |

### 场景 3：云服务器

把 `relay_server.py` 部署到有公网 IP 的服务器，手机填 `http://服务器IP:8860` 或绑定域名。

## 二、怎么接智能体

**原理**：每个智能体用 `agent-relay` 注册为中继上的一个「agent 设备」，名字不同 → 手机端就是不同会话。

```bash
cd D:\编程\agent-pilot\agent-relay
```

### 接入 WorkBuddy（我）

我直接通过命令行发消息，你在对话里让我发就行：

```bash
# 发一条消息到手机
python -m agent_relay --relay http://<中继地址>:8860 --name WorkBuddy send phone "任务完成 ✅"

# 工具进度（同 message_id = 编辑原消息）
python -m agent_relay --relay http://<中继地址>:8860 --name WorkBuddy tool m1 xcodebuild running "构建中…"
python -m agent_relay --relay http://<中继地址>:8860 --name WorkBuddy tool m1 xcodebuild done "构建完成"

# 任务状态
python -m agent_relay --relay http://<中继地址>:8860 --name WorkBuddy task t1 "部署" --status running --progress 0.5

# 等手机回复
python -m agent_relay --relay http://<中继地址>:8860 --name WorkBuddy listen --timeout 120
```

### 接入 Codex（OpenAI Codex CLI）

**方式 A：MCP**（推荐）。`pip install mcp`，然后在 Codex 的 MCP 配置（`~/.codex/mcp.json` 或 IDE 设置）加：

```json
{
  "mcpServers": {
    "agent-relay": {
      "command": "python",
      "args": ["-m", "agent_relay.mcp_server"],
      "env": {
        "AGENT_RELAY_URL": "http://<中继地址>:8860",
        "AGENT_RELAY_NAME": "Codex"
      }
    }
  }
}
```

**方式 B：CLI**。在 Codex 的 shell 里直接 `python -m agent_relay --relay ... --name Codex send phone "..."`。

### 接入 Cuckoo-Code

Cuckoo Code 用 Claude Desktop 兼容格式的 MCP。编辑 `~/.cuckoo/mcp.json`（用户级，所有项目通用）：

```json
{
  "mcpServers": {
    "agent-relay": {
      "command": "python",
      "args": ["-m", "agent_relay.mcp_server"],
      "env": {
        "AGENT_RELAY_URL": "http://<中继地址>:8860",
        "AGENT_RELAY_NAME": "Cuckoo-Code"
      }
    }
  }
}
```

> 注意 `args` 里 `-m agent_relay.mcp_server` 需要 `agent-relay/agent_relay` 目录在 Python 能找到的路径上，最简单是 `cd` 到 `agent-relay` 目录再启动 Cuckoo，或用绝对路径 `python /绝对路径/agent_relay/mcp_server.py`。

### 接入其它（Claude Code / Cursor 等）

凡是支持 MCP 的，把上面 JSON 里的 `command`/`env` 原样加进对应 MCP 配置即可；不支持 MCP 的用 CLI 方式。

## 三、会话列表怎么显示

App 端按**智能体名字**自动分会话：

- 每个 `--name` 对应一个独立 deviceId（agent-relay 已按名字持久化，同一智能体永远是同一会话）
- 智能体第一次发消息，手机侧栏「智能体」分组就出现对应会话（头像 + 名字 + 最后一条消息 + 未读角标 + 在线状态点）
- 多个智能体 = 多个会话，按最近消息排序
- 也可以在 App「设置 → 在线智能体」里看到已接入的智能体，点「对话」主动发起会话

示例：接入 WorkBuddy、Codex、Cuckoo-Code 后，侧栏会显示三个会话：

```
智能体控制台
  工作台
    📋 开发任务
    ⚙️ 设置
  智能体  ● 已连接
    🧠 WorkBuddy   构建完成 ✅    2
    💻 Codex       读取文件完成    1
    🤖 Cuckoo-Code 正在重构…     1
```
